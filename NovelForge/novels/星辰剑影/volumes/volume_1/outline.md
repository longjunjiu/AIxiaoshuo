# 第一卷 青云宗

## 第一章 落魄少年

**章节概要**：陈墨是青云宗的杂役弟子，出身被灭门的陈家，性格沉默但内心坚韧。一日，他在后山砍柴时意外发现一柄断裂的古剑，触发了沉睡万年的剑灵。

**核心事件**：
1. 陈墨在后山砍柴，回忆身世
2. 发现古剑碎片，以血祭剑
3. 剑灵苏醒，传授基础剑法
4. 被周长老发现其惊人天赋

**伏笔**：
- 陈家的灭门与古剑有关
- 周长老似乎认识陈墨的父亲

**角色出场**：
- 陈墨（主角）
- 周长老（引路人）

## 第二章 拜师

**章节概要**：陈墨被周长老收为记名弟子，开始正式修炼。他的修炼速度远超常人，引起了一些人的注意和嫉妒。

**核心事件**：
1. 周长老公开收徒
2. 赵无极等人嘲笑陈墨
3. 陈墨展现惊人天赋
4. 苏晴雪出现，与陈墨重逢

**伏笔**：
- 赵无极的背景不简单
- 苏晴雪的特殊体质

## 第三章 宗门大比

**章节概要**：青云宗举行宗门大比，陈墨被迫参赛。在比赛中，他展现出惊人的剑道天赋，震惊全场。

**核心事件**：
1. 宗门大比开幕
2. 陈墨连胜数场
3. 对战赵无极
4. 展现剑心通明体质

**冲突**：
- 赵无极使用暗招
- 陈墨反败为胜

## 第四章 暗流涌动

**章节概要**：陈墨的表现引起了魔道的注意，同时也触动了某些人的利益。一场针对他的阴谋正在酝酿。

**核心事件**：
1. 魔道中人潜入宗门
2. 陈墨遭遇暗杀
3. 老道士出手相救
4. 发现更大的秘密

**伏笔**：
- 老道士的真实身份
- 魔道对陈墨的兴趣

## 第五章 传承

**章节概要**：老道士决定传授陈墨一门绝世功法，同时也告诉他关于陈家灭门的更多真相。

**核心事件**：
1. 老道士揭示身份
2. 传授上古功法
3. 讲述陈家往事
4. 陈墨获得新能力

**转折**：
- 陈墨知道仇人是谁
- 新的挑战即将到来
